# Lineside
Focus for as long as the journey takes.

Lineside is a calm train-journey focus app set on the Velloran Regional Railway. Pick a line, choose a train and where to go, and depart: the trip lasts as long as the real journey would, so you work while it runs. Look out the window as the seasons and the time of day change.

## Download (beta)
Go to **Releases** (right side of this page) and download the zip for your computer:
- Windows: `Lineside-0.6.0-beta-win64.zip`
- Mac: `Lineside-0.6.0-beta-mac.zip`

Ignore the "Source code" files. Those aren't the app.

## Opening it
**Windows:** unzip first (right-click → Extract All), then open Lineside.exe. If Windows says "Windows protected your PC", click More info → Run anyway. The beta isn't code-signed yet.

**Mac:** unzip, drag Lineside into Applications and open it. If macOS blocks it, go to System Settings → Privacy & Security → Open Anyway. The beta isn't notarized yet.

Full steps are in READ ME FIRST.txt inside the zip.

## Your progress
Your trips and unlocks are kept in logbook.json, outside the app, so a newer version carries on where you left off.

## Found a problem?
Settings (the gear) → Feedback → Copy report, then paste it into a message to me with what happened. Lineside sends nothing by itself.
